## 🎨 界面重做（玻璃拟态设计系统）

- **真毛玻璃，不再是半透明色块**：主窗口与所有弹窗调用 DWM 系统级 Acrylic（`DWMWA_SYSTEMBACKDROP_TYPE`），背后桌面被**真正模糊**；悬浮面板走分层窗口的 `SetWindowCompositionAttribute` 磨砂路径。
- **分层透明 + 玻璃厚度感**：窗口底 → 侧栏 → 卡片 → 悬浮层逐层递进，每层玻璃上缘一道 1px 高光反光层（Specular Highlight）、下缘收暗；背景内嵌极光色斑（Aura Brand Gradient：天蓝 `#38BDF8` ➔ 皇家靛蓝 `#6366F1` ➔ 霓虹电紫 `#A855F7`），透出彩色光影。
- **主窗口换自绘标题栏**：去掉原生旧式系统标题栏，改为自绘沉浸式标题栏（支持拖动 / 最小化 / 最大化 / 关闭），配合 16px 圆角窗口与系统圆角阴影。
  - **品牌 Header**：左上角极光徽章 + 极光副标，右上角实时状态胶囊（`● 全局监听已就绪`，翠绿呼吸圆点）。
  - **分组侧边栏**：导航项按 `核心操作`、`快捷触发`、`首选项` 分组，搭配 34x34 圆角微卡片图标与平滑胶囊激活态。
  - **快捷唤出指引卡**：底部常驻磨砂亚克力呼出提示卡片（`<kbd>鼠标中键</kbd>` / `<kbd>快击 Ctrl</kbd>`）。
- **唤出式磁贴面板 (`PanelWindow`)**：
  - **外壳与光效**：18px 大圆角与 36px 柔和弥散阴影，背景融入极光漫射微光，悬浮于桌面宛如发光磨砂玻璃。
  - **顶部操作栏**：品牌松石蓝圆角微徽标与极简图标按钮组，强化沉浸感。
  - **Spotlight 聚光灯即时搜索**：居中呼吸感圆角搜索栏、天蓝搜索微图标与 `<kbd>ESC</kbd>` 键帽提示，即打即显。
  - **磁贴网格**：13px 平滑圆角磁贴，顶部融入 1px 半透明高光反光层，悬停时光晕边框与微上浮效果相呼应；空位采用圆角浅色加号容器。
- **桌面悬浮气泡球 (`FloatingButtonWindow`)**：
  - 升级为多层立体质感的发光玻璃微球体（Ambient Glass Orb），具备渐变外发光光晕（Outer Glow）、柔和下坠阴影与顶部镜面反光层，内部闪电图标立体悬浮。
- **动作管理与场景管理 (`ActionsManagerView`, `ScenesManagerView`)**：
  - 动作列表新增即时搜索过滤框（SearchBox），支持快速模糊检索动作；列表项升级为带有 42x42 发光微卡片图标、加粗主标题、分类胶囊芯片与快捷键键帽的现代化卡片行。
- **文本指令与热键管理 (`TextCommandsView`, `HotkeysView`)**：
  - 缩写词与组合键以立体 `<kbd>` 键帽徽章呈现，操作目标与开关状态清晰可见。
- **统一弹窗外壳 (`DialogShell`)**：
  - 16 个弹窗/编辑器共用同一个窗口模板 —— 16px 圆角玻璃面板 + 标题条（含关闭按钮），关闭按钮绑定系统命令，无需各窗口重复编写事件。

  - 动作编辑器、场景编辑器、热键编辑器等统一改为「标签在上、控件在下」的字段布局，间距、字阶、按钮位置全应用一致。

  - 按键捕获弹窗 (`KeyCaptureDialog`)：赛博微发光按键采集卡片、霓虹内发光边框与立体键帽提示。
  - 图标选择器 (`IconPickerDialog`)：极光预览卡片、圆角 Emoji 磁贴微网格、更通透的标签页与配色切换。

## 🌓 深色 / 浅色双主题

- **分段开关**：设置页新增 **「跟随系统 / 浅色 / 深色」** 分段胶囊开关，切换立即生效，无需重启。
- **系统联动**：跟随系统时，通过 `WM_SETTINGCHANGE` 实时响应系统主题变化；系统标题栏配色同步切换，不会出现「深色内容 + 浅色标题栏」的割裂。

## 🐛 修复

- **悬浮面板底栏（页码 / 翻页按钮）从未显示过**：`DockPanel` 中 `ScrollViewer` 抢占了底栏空间。现改为 Grid 行高自适应，并按**实际测量高度**决定窗口高度，不再靠魔法数字推算。
- **`pack://application` 资源依赖「入口程序集就是本程序」**：一旦被别的宿主加载就会抛 `XamlParseException`（项目历史日志里反复出现「找不到资源 assets/app.ico」）。现改为程序集限定 URI（`/QuickLauncher.App;component/...`），不再挑宿主。
- **运行时改色会崩**：WPF 会冻结被多处共享引用的画笔，改写其 `Color` 抛「指定属性为只读」。现改为消费端 `DynamicResource` + 切换主题时替换画笔实例。

# v1.0.1

> 发布日期：2026-11-01 ｜ 修复与工程改进
> ⚠️ 本次发布产物**未做 Authenticode 数字签名**（开源版不需要证书，也不会向系统添加任何证书）；
> 请用 Release 页附带的 `SHA256SUMS.txt` 校验完整性。
> 想启用「在任务管理器/yuzu 等管理员窗口内唤出面板」的 UIAccess 能力，请看
> [`docs/第2步-UIAccess改造计划.md`](第2步-UIAccess改造计划.md)。

## 🐛 修复
- **开机自启不再弹出主窗口**：此前 `OnStartup` 无条件 `Show()` 主窗口，每次登录都会弹出「动作管理」窗口。现在自启项带 `--autostart` 参数，**静默启动、只驻留托盘**，双击托盘图标可打开主窗口；也可在「设置 → 常规 → 开机启动时显示主窗口」勾选后改为开机即显示。
- **持久变量跨次运行读不回来**：state 文件的键带 `$var:` 前缀，而运行时变量表里也带着前缀，导致 `{变量名}` 插值、`ctx.Get()`、脚本读取全部取不到 —— 变量变成「只写不读」。现已在加载时剥离前缀。
- **表达式中的字符串比较恒为假**：`{状态} == "已完成"` 会被先做文本插值变成裸文本 `已完成 == "已完成"`，解析器当作标识符查找失败 → 条件恒 false。现改为表达式求值器原生支持 `{变量}` 引用。
- **自触发防护失效**：`Suppress()` 的 `using` 写在 `Task.Run` 之外，动作还在执行时抑制计数就已释放，动作合成的键鼠输入会被自身钩子重新捕获 → 回环触发。现改为覆盖整个执行期，抑制计数改用 `Interlocked/Volatile` 保证跨线程可见。
- **C# 脚本超时完全失效**：Roslyn 的 `RunAsync` 会同步执行脚本体，死循环脚本会把调用线程永久挂死（`task.Wait` 的返回值也被忽略）。现将编译+执行整体移入线程池线程并真正 enforce 超时。
- **「运行命令」带输出变量必崩**：`UseShellExecute` 与重定向输出互斥导致 `Process.Start` 抛异常。现按场景分流，并改用异步读取避免管道死锁。
- **`Application.Current` 为空时崩溃**：`App.Settings` 的强制转换会抛空引用（关闭期钩子回调可触发）。现已改为空安全。

## 🔧 改进
- **双清单变体**：UIAccess 从「改仓库里的文件」改为构建开关 `-p:UIAccessManifest=true`，默认清单保持 `uiAccess="false"` —— **任何人 clone 后都能直接构建运行，不再需要证书**。
- **测试与 CI**：修复了 9 个失败用例的根因（测试宿主未创建 `Application` 实例，导致 XAML 资源加载失败），测试数 14 → **89**，CI 的排除过滤条件整段删除，**CI 从长期红灯变为全绿**；同时消除了一个依赖真实键盘状态的随机失败用例。
- **产物名改为 ASCII**：`速动-Setup.exe` 在 GitHub Release 上传环节会被编码降级成 `-Setup.exe`（用户下载到一眼像恶意文件的名字）。现统一为 `Sudong-*`，并由 CI 自动生成 `SHA256SUMS.txt` 随 Release 发布。
- **本地自签名安装包明确告知证书信任**：`build\sudong.iss` 打出的自签名版安装包会导入一张自签名根证书（UIAccess 的硬前提，不可跳过——证书不受信时该程序根本无法启动）。现在改为**安装开始前弹窗明确告知**：加的是哪张证书、导入到哪两个存储、为什么需要、意味着什么（本机上由该证书签名的程序都会被信任）、如何撤销；**卸载时自动删除该证书**。不想加这张证书的用户请用本 Release 的开源版安装包（不导入任何证书）。
