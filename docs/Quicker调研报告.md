# Quicker 调研报告

> 来源：getquicker.net 官方文档（KC/Manual 使用手册、KC/Help 组合动作开发）、docs.getquicker.net（2.0）。均为官方文档可确认事实，未确认处已标注。

## 核心要点（约 1500 字）

### 1. 交互模型
双入口：**网格面板窗口** + **轮盘菜单**，二者共享同一套"操作类型"定义。
- 面板：默认**单击鼠标中键**或**快击 Ctrl**（>200ms 视为普通键）弹出；上半=全局面板（不随程序变），下半=上下文面板（按当前进程自动加载对应动作页，无则加载"通用"页）；流程为"选中对象→弹出→点动作→自动关闭"，可开"按钮上松开即执行"实现按下滑动松开的一键触发；滚轮悬停翻页，腰栏含搜索/锁定/钉住。
- 轮盘：自设一个鼠标键（常用中键），**按住立即移动**弹出，滑到扇形位松开触发；滑出轮盘触发第三圈"扩展圈"（不可见、覆盖全屏、适合盲操作）；Esc 取消。三圈结构：内圈、外圈（默认 8 位/圈，专业版 16）、扩展圈（8 方向）。场景覆盖：程序场景有则用、否则回落全局；滚轮上滚切全局轮盘、下滚切仅当前程序。增强：位上连按 F1 重复触发；位可绑"按键触发"（键/鼠键/滚轮四向/任意键传参）；左 Shift=动作右键菜单、右 Shift=调试运行。
- 官方**没有**方形/十字面板；轮盘每场景仅一页，多轮盘靠"高级鼠标触发+自定义场景"变通。

### 2. 动作类型
- **简单动作 6 种**：模拟按键、运行程序/打开文件（含命令）、打开网址、发送文本、切换动作页、执行脚本。
- **快速操作 8 种**（轮盘/文本指令/扩展热键/左键辅助/高级鼠标触发共用）：无操作、发送快捷键、键入内容（按键语法）、键入纯文本、粘贴纯文本、粘贴 HTML、多步骤输入、常用功能、运行 Quicker 动作、打开或运行、键鼠控制。文本参数支持 `{cliptext}`/`{selection}`/`{0:日期格式}`/`FILE:路径`。
- **组合动作**=有序步骤+变量+子程序。官方模块约 130 个，分 11 大类（常用/界面交互/文本/图片/剪贴板/文件/系统/计算/程序流/网络/第三方软件），含 OCR、Everything 搜索、浏览器控制（CDP）、UIA 窗口自动化、Excel/Office/Adobe/CAD 控制、AI 调用、HTTP 服务器等。完整清单见附录 A。

### 3. 动作数据结构
步骤=模块+输入参数+输出参数；参数支持静态值、变量、文本插值、表达式。变量类型：文本/数字/布尔/词典/列表/表格/日期/动态对象，可标"状态变量"持久化。子程序=函数，分动作内/公共/网络共享三类，经变量输入输出标记传参。自定义右键菜单是一段文本定义（每行`外观|参数值`，`[fa:图标]`、`(tooltip)`、`----`、缩进=子菜单），点击即以该参数运行动作，动作内判断 `quicker_in_param` 分支。动作属性还含图标（图片/SVG/字符）、可见性表达式、快捷键、滚轮连续触发。

### 4. 设置项
- 面板弹出：鼠标（按下中键/X1/X2、Ctrl+中键/右键、长按、按住右键滑动、**画圈激活**、滚轮左击）+键盘（单击 Ctrl、全局快捷键）+触发浮标；可设跟随鼠标、自动激活鼠标位窗口。
- 触发体系：轮盘、鼠标手势、扩展热键（引导键+动作键，可 3 键）、文本指令、左键辅助、**高级鼠标触发**（鼠标动作+屏幕位置+修饰键+黑白名单的规则引擎，按序匹配）、按键双击、热键联动、自动运行动作、事件触发。
- 上下文：以"场景"（全局/应用程序/自定义）为单位按进程名匹配；每场景配动作页、轮盘、手势、禁用项、黑名单、全屏禁用、动作页主机绑定。
- 外观：面板主题/颜色、深色模式、轮盘格数、外观库分享。文本指令：缩写词+触发字符（默认 Tab）、正则传参、绑进程、输入法上屏处理。

### 5. 进阶功能
动作库/子程序库/外观库/扩展热键包/文本指令包均以网址分享安装、可检查更新，有积分机制。云同步：**客户端单向触发**（改动后免费 60s/专业 0–15s 无新改动才传，开机/联网重连同步），无实时推送，免费版绑 2 台设备，凭据 100 天有效；不同步动作历史、状态数据、运行期文件。其他：HTTP 服务器、WebSocket、公共 API、推送服务（手机 APP/多客户端）、剪贴板内容上下文菜单、悬浮动作按钮/动作页、文本悬浮窗、仪表盘、快速截图。2.0（Preview/专业版）新增截图贴图、软件 Bridge、AI 写动作。

### 6. 架构特点
- 全局键鼠低级钩子；CPU 繁忙超时会被 Windows 回收，需"重载钩子"+自动检测+键盘状态重置；与第三方手势软件互斥。
- 存储（`%LOCALAPPDATA%\Quicker\`）：`data/quicker.db`（全部定义数据，官方未明确加密细节）、`imagecache/`、`logs/quicker.log`、`states/state_动作id.json`、`文档\Quicker`（组件与动作数据）。
- 脚本引擎：C#=CS-Script(v1)/Roslyn(v2)，普通模式进程内经 `IStepContext` 读写变量，低权限模式交 LPAgent 代理进程；JS=Jint(1.43.7+，早期 Jurassic)；Python=pythonnet(Python.Runtime，3.7–3.12，进程内)。可选执行线程（UI/MTA/STA/STA 独立）。

## 附录 B：文本指令细节
缩写词须为可直接键入字符；触发字符默认 Tab（可每条自定义）；支持正则匹配（匹配内容或正则组作参数，`param1={$1}`）；输入法开启时按"全部上屏/全部不上屏"选择退格或 Esc 消除；可绑定多进程；以"配置包"形式分享。

## 附录 C：扩展热键细节
引导键+动作键（可加修饰键成 3 键）；单独按引导键可设操作（动作键留空，每引导键限一条）；不建议用左 Ctrl/Alt/Shift/Win 作引导键；参数含触发间隔、连续按键检测（按抬起顺序区分普通输入与热键）、提示窗延时、长按取消间隔；长按引导键 2–3s 显示该引导键全部组合提示。

## 附录 D：与常见误解的澄清
1. 轮盘触发键无强制默认值，需在设置指定且不能与其他功能共用。
2. 官方无方形/十字面板；网格面板+轮盘是仅有两种形态。
3. "加密 SQLite"未见官方明文，仅确认 quicker.db 为本地数据文件。
4. 轮盘每场景仅一页；多轮盘需高级鼠标触发+自定义场景。
5. 云同步为客户端单向、非实时；多机同时在线有覆盖风险。
